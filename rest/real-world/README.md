# REST Real-world — Product Catalog

> 🔜 Coming soon

## What we'll build

An e-commerce product catalog API with search, filtering, and pagination — the kind of backend behind a real shopping site.

## Concepts this adds over the simple example

- Pagination (`?page=0&size=20`)
- Search and filtering (`?category=electronics&maxPrice=500`)
- Relations — products belong to categories
- Real database — Postgres with Spring Data JPA

## Planned stack

- **Server:** Spring Boot + Spring Data JPA + Postgres
- **Client:** React + search/filter UI
