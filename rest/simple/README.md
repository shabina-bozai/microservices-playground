# REST Simple — Todo CRUD API

> 🔜 Coming soon

## What we'll build

A todo list API with full Create, Read, Update, Delete operations.

## Planned stack

- **Server:** Spring Boot + Spring Data JPA + H2 (in-memory database)
- **Client:** React + fetch API

## Endpoints planned

| Method | Path | Description |
|---|---|---|
| GET | `/api/todos` | Get all todos |
| GET | `/api/todos/{id}` | Get one todo |
| POST | `/api/todos` | Create a todo |
| PUT | `/api/todos/{id}` | Update a todo |
| DELETE | `/api/todos/{id}` | Delete a todo |
